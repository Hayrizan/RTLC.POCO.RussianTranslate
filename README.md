# Русификатор Poco

Плагин для Steam-сборки 19385591, Unity 2022.3.1f1 Mono x64 и BepInEx 5 для Windows x64.

## Установка

1. Скачайте RTLC.POCO.RussianTranslate.zip из [релиза v0.1.0](https://github.com/Hayrizan/RTLC.POCO.RussianTranslate/releases/tag/v0.1.0).
2. Закройте игру и распакуйте содержимое архива в папку с Poco.exe. BepInEx 5.4.23.6 для Windows x64 входит в комплект.
3. Запустите Poco через Steam. Журнал загрузки находится в BepInEx/LogOutput.log.

Для удаления перевода уберите папку BepInEx/plugins/RTLC.Poco.RussianTranslate.

## Сборка

1. Запустите tools/build_bundle.ps1. Скрипт собирает build/rtlc.bundle из папки content. Путь к редактору можно передать параметром -UnityEditor.
2. Выполните dotnet build src -c Release. Если игра находится в другом каталоге, передайте параметр -p:GameDir="ПУТЬ_К_ИГРЕ".
3. Для установки возьмите DLL из src/bin/Release/netstandard2.1 и rtlc.bundle из build.

## Редактирование перевода

В content/Russian.json массив dialogue содержит реплики и варианты ответа, а ui содержит интерфейс, имена, предметы и подсказки. Редактируйте значения ru. Ключи en включая пробелы и переносы, а также игровые теги форматирования и эффектов должны сохраняться.

Галочка «Перевод реплик Поко» находится под «Всегда бегать». По умолчанию Поко говорит символами. Галочка включает русский перевод обычным игровым шрифтом. Выбор сохраняется между запусками.

Poco-Cyrillic-v1.004-Regular.ttf упакован как динамический шрифт Unity. Плагин использует его как источник кириллицы для TextMeshPro и обычного Unity UI Text.

## Редактирование текстур

Кладите исходные PNG в content/Textures и пересобирайте бандл. Имя файла должно совпадать с именем Unity Texture2D. Сохраняйте исходный размер и прозрачность.

Имена с размерами, например Logo.1265x544.png для главного меню и финала, имеют приоритет над именами без размеров. Из Logo.png размером 1280×720 плагин автоматически берёт область 1265×544 для малого логотипа. Плагин заменяет пиксели в памяти, сохраняя ссылки на текстуру и её спрайты.
